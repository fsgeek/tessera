**Composition observation (scorer, criteria-level, labeled as such).**
The witness is not an alternative to the TLR; as corrected, it *is*
the TLR plus an inclusion proof. The candidates are therefore not
exclusive: issue the TLR always, in-bundle, load-bearing; log it and
carry the receipt as **optional enrichment** where an issuance class
wants equivocation visibility — receipts never load-bearing. That
composition keeps C2 at zero new *required* custody subjects while
leaving the enrichment available, and it is, verbatim, the
SCITT-shaped thesis already in the record ("standing carried in-band,
receipts as optional enrichment"). It is an input to the rule-3 fork,
not a selection.
